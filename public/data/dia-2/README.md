# アプリ用データの仕様
時刻はすべて「0時0分0秒からの経過秒」。86400以上は翌日(24:00以降)。-1は「その駅に着/発なし」(始発の着、終着の発)。

## 列車番号と運行番号(東急方式)
- 運行番号 = 編成の1日の動き(電車の前面に出す番号)。例: 51K。数字2桁+K。運用番号(Y-急行-03など)と1対1。
  帯: 01〜39=各停・普通、41〜60=区間快速・快速・通勤特快、61〜79=急行・特別快速、81〜99=有料特急。
- 列車番号 = 6桁。[車両の所属 1桁][運行番号 2桁][始発駅を出る時 2桁][方向・順序 1桁]。例: 151071 = 所属1(七光台)・運行番号51・7時台・下り1本目。
  方向・順序は、下りが1,3,5…、上りが2,4,6…(同じ編成が同じ時間に同じ向きで複数走るとき順に増える)。環状線は正回りが奇数、逆回りが偶数。
  所属: 0=丸の内検車区(神埼高速線・埼千環状線) 1=七光台車両管理センター(神埼線) 2=松戸車両管理センター(土浦線)。
  回送は先頭に「回」(回151071 など)。出庫は末尾1、入庫は末尾2。
- 列車番号は、所属ごとに運行番号が重ならないので、全路線で一意。運行番号は所属が違えば同じ数字がある。

## 直通列車(路線をまたぐ列車)
- 大宮でクロス(神埼線と埼千環状線)・松戸で接続(土浦線と埼千環状線)する列車は、2つの路線にまたがって走る。同じ列車番号が、通る路線それぞれの *_trains.json に、その路線を走る部分だけ入る。
  乗り換え駅(大宮・松戸)では、前の路線の最後の駅(着のみ)と、次の路線の最初の駅(発のみ)に分かれて載る。
- 直通の種別: 特急めぐり(東京〜日立)・特別快速(東京直通)・通勤特快(東京直通)(東京〜茨城空港)、急行(越谷経由)・各停(越谷経由)(東京→越谷レイクタウン→大宮→池袋→東京)、急行(柏経由)・各停(柏経由)(東京→柏→大宮→横浜)。
- 編成(運用)は、車庫のある所属の路線に入る(めぐり・特別快速・通勤特快は土浦線、越谷経由・柏経由は神埼線)。運用.json は駅名で持つ。

## 配線.json
{路線名: {駅名: {"配線": 型, "折返し線": 数, "引上線": 数}}}
- 型: 2面2線 / 2面4線①(待避線だけにホーム) / 2面4線②(通過線と待避線の間にホーム=緩急接続) / 2面6線 / 頭端式N線 / 東京は通り抜け・終点共用のN線。
- 東京は 神埼高速2線・神埼3線・埼千環状4線。終点用の線と通り抜けの線を同じ群として割り当てる。
- 番線の取り合い(同じ線に重なる列車)は 番線の取り合い.csv に残してある。重なりは数十秒〜1分ほどで、安全のための前後の余裕と重なる分。

## master.json
{路線コード: {name, loop(環状か), dirs(方向コード2つ), stations: [[駅名, 起点からのキロ], ...], types: [[種別名, 略称, 有料(0/1)], ...]}}
- 駅番号 = stations の添字。環状線の東京は1つ(最初と最後で同じ番号)。
- 種別番号 = types の添字。

## {路線}_trains.json
列車の配列。1列車 = [列車番号, 種別番号, 方向, 運用番号, 始発の発車秒, [駅番号, 着(始発秒からの差), 発(始発秒からの差), ...3つずつ], 運行番号, 行先の駅名, 始発の駅名, [停車駅ごとの番線...]]
- 最後の配列は、flat と同じ順の停車駅ごとの番線(例: "2")。番線は路線ごとの駅の配線(配線.json)で決まり、駅の同じ番線番号でも上り・下りで別の線になる。
- **行先・始発は列車全体のもの**。直通列車は、このファイルに載っている最後の駅(乗り換え駅)ではなく、別の路線へ続く最終の行先(例: めぐりは東京)が入る。「○○行き」「当駅始発」の表示は、この2つを使うこと。
- 停車駅だけを順に並べる(通過駅は載せない)。実際の着秒 = 始発の発車秒 + 差。
- 配列の添字 = 駅ファイルの「列車の番号」。

## 運用.json
{路線コード(所属する路線): {運用番号: [[列車番号, 発駅名, 発秒, 着駅名, 着秒], ...時刻順]}}  ※路線をまたぐ編成は駅名で持つ
運行番号.json は {路線コード: {運用番号: 運行番号}}。
- 1つの運用番号 = 1編成の1日。先頭が出庫、最後が入庫(車庫との回送)。列車番号は *_trains.json と同じ。出庫・入庫の回送は「回」で始まる番号。
- 回送は営業列車と2分以上あけて走れる時刻にしてある。駅で待つ時間(留置)が長い編成もある。

## {路線}_st{駅番号}.json
{方向: [[発車秒, 種別番号, trains.jsonの添字], ...]} を発車秒順に並べたもの。終着のみの方向は空配列。
