# アプリ用データの仕様
時刻はすべて「0時0分0秒からの経過秒」。86400以上は翌日(24:00以降)。-1は「その駅に着/発なし」(始発の着、終着の発)。

## master.json
{路線コード: {name, loop(環状か), dirs(方向コード2つ), stations: [[駅名, 起点からのキロ], ...], types: [[種別名, 略称, 有料(0/1)], ...]}}
- 駅番号 = stations の添字。環状線の東京は1つ(最初と最後で同じ番号)。
- 種別番号 = types の添字。

## {路線}_trains.json
列車の配列。1列車 = [列車番号, 種別番号, 方向, 運用番号, 始発の発車秒, [駅番号, 着(始発秒からの差), 発(始発秒からの差), ...3つずつ]]
- 停車駅だけを順に並べる(通過駅は載せない)。実際の着秒 = 始発の発車秒 + 差。
- 配列の添字 = 駅ファイルの「列車の番号」。

## 運用.json
{路線コード: {運用番号: [[列車番号か"出庫"/"入庫", 発駅番号, 発秒, 着駅番号, 着秒], ...時刻順]}}
- 1つの運用番号 = 1編成の1日。先頭が出庫、最後が入庫(車庫との回送)。列車番号は *_trains.json の列車番号と同じ。
- 回送は営業列車と2分以上あけて走れる時刻にしてある。駅で待つ時間(留置)が長い編成もある。

## {路線}_st{駅番号}.json
{方向: [[発車秒, 種別番号, trains.jsonの添字], ...]} を発車秒順に並べたもの。終着のみの方向は空配列。
